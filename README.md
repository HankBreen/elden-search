## Welcome to Elden Search

- Elden Search is an Elden Ring search engine that helps players find weapons that suit their wants and needs
- You can scroll through all the weapons in the game, and filter based on weapon type
- Use the search function to describe your ideal weapon and see recommendations based on your description
- Try searching something like "giant sword that deals fire damage" and see what comes up, the possibilities are endless!
- Try it for yourself at [Elden Search](https://elden-search.vercel.app/)
